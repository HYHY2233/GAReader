# GAReader

用于阅读和分享英中对照论文的本地网站，提供正常登录与注册、可记住昵称的匿名登录、全文评论、两项独立评分、主题与字号设置，以及划词 Google 检索。

完整源码、Windows 启动脚本、锁定依赖、测试和文章模板均在本仓库中。首次安装会导入 `examples/` 中的 IDAES 和柔性合成氨两篇示例译稿（附原文 PDF 与段落映射）。仓库不含任何用户数据库、真实配置、登录凭据或运行备份。

## 第一次使用

1. 安装 Python 3.12，克隆仓库或通过 **Code → Download ZIP** 下载并解压到本地非同步目录。
2. 双击 **setup.cmd**，等待依赖安装、数据库初始化和示例论文导入完成。首次安装需要联网下载依赖。
3. 双击 **start.cmd**，保留这个窗口。
4. 浏览器打开 **http://127.0.0.1:8000/**，用登录名和密码登录。没有账户时点击 **注册**，设置登录名、密码和确认密码，昵称可选；注册成功后直接登录。
5. 登录、注册区域旁边提供 **匿名登录**。首次使用自动生成昵称；以后优先显示 **使用上次身份登录**，也可展开 **更换匿名身份**，单独生成新身份。

匿名身份会在当前浏览器记住，退出登录或登录会话失效后仍可选择上次身份，继续查看、修改原来的评论和评分。每次匿名登录将记忆有效期续为一年。此功能通过浏览器保存的签名凭据恢复同一身份，不接受单凭昵称取回身份。清除本站浏览器数据、换浏览器或恢复备份后更换服务器密钥，会失去这份记忆。更换身份后记住新的昵称，旧记录仍保留在原身份下。

匿名读者和自行注册的账户都是普通成员，可阅读、上传标准译稿、评论和评分，没有管理权限。注册账户通过密码登录，支持跨浏览器使用；匿名身份不会自动合并到注册账户。昵称末尾的小编号用于区分重名。

管理员也从登录页输入登录名和密码。创建管理员时，先停止网站，双击 **manage-account.cmd**，输入 `1` 创建管理员，再启动网站。密码输入不显示，至少 10 位，无默认密码。登录后右上角提供 **管理**，可管理成员、分类、论文和评论。原 `/account/login/` 地址保留兼容。

## 每天使用

- 启动：双击 **start.cmd**。已有本应用运行时会显示现有地址。
- 停止：在启动窗口按 **Ctrl+C**；若 Windows 询问 `Terminate batch job (Y/N)?`，输入 **Y**。关闭窗口或电脑休眠也会中断访问。
- 端口冲突：不会结束其他程序。可在本目录终端执行 `start.cmd --port 8001`，地址相应为 `http://127.0.0.1:8001/`。
- 日常启动不联网安装、不重新导入、不清空数据。仅首次安装或明确维护时运行 **setup.cmd**。

默认只允许本机访问，尚未配置局域网共享、防火墙、域名、HTTPS、开机自启或系统服务。以后需要给同事在线访问时，再配置网络和 HTTPS；请勿直接将监听地址改成公网地址。

## 阅读与分享

首页按分类筛选、用中英文题名／作者／分享说明检索，可按添加时间或任一评分排序。没有综合分。

阅读页保留段落英中对照、章节／图／表／公式目录、文内搜索、图片放大、字号、亮色／暗色／护眼／跟随系统主题及来源显示。桌面左右对照，手机每个段落英文在上、中文在下；长公式与表格在局部横向滚动。来源和版本说明折叠保存，完整科学内容未因清理删减。

主题、字号和段落来源开关直接显示在阅读页顶部，目录、文内查找、Google、评分和评论入口也在顶部。选中正文中的一段文字后，点击浮动的 **Google 检索** 按钮，在浏览器小窗口中检索；也可点击顶部 **Google** 手动输入，或按 **Alt+G**。弹窗被拦截时提供 **新标签页打开**。仅点击检索才发送关键词，正文不会由服务器自动转发。超过 2000 字的选择会保留在编辑框中，先精简再检索。

两项评分分别为“有意思”“重要性”，每项 1—5 分，均可独立修改和撤回。未评分不计作 0。显示均值保留一位小数，排序使用未四舍五入的原均值。

评论是全文纯文字评论，可回复一层。成员可编辑／删除自己的评论；管理员可隐藏不合适内容，不能代写别人评论。删除根评论后已有回复保留。

主题、字号和阅读位置只保存在当前浏览器，按**账户＋论文＋内容哈希＋格式版本**隔离。清除浏览器数据会清除这些本地设置；账户评分与评论仍在数据库中。网址中的明确锚点优先于旧阅读位置。不提供跨设备阅读位置同步。

## 上传格式

选择 **上传论文** → 提交标准双语 HTML → 检查安全预览与校验摘要 → 勾选确认 → 发布。

- 必填：自包含、UTF-8 的 `.html`，以及至少一个分类。
- 支持包内两种现成格式 `idaes-pair-v1`、`ammonia-pair-v2`。标题自动提取，提取失败时需补全中英文标题。
- 可选：分享说明、作者、年份、来源链接、PDF、段落映射 JSON。没有 PDF 或映射也能发布。
- 不能上传任意网页、单语 HTML、PDF 单文件、Word、Markdown 或 ZIP 作为论文。
- 大小上限：HTML 50 MiB、PDF 100 MiB、映射 5 MiB，单次请求 160 MiB。图片仅内嵌 PNG/JPEG/WebP，单图 20 MiB、4000 万像素，所有图片 120 MiB；180000 个节点／100 层嵌套。
- 原始 HTML 哈希相同则拒绝重复上传，包括已隐藏的论文。相近题名或相同来源链接仅提示，不自动合并。
- 暂存预览仅本人可读，24 小时后失效；启动和后续上传时清理过期文件。

具体格式见 `specs/ARTICLE_FORMAT.md`。模板 `templates/standard_bilingual_article.html` 是未完成骨架，不能作为第三篇论文发布。

上传脚本、事件、危险链接和原页面工具不运行；统一使用网站的阅读器。文本、原图字节、MathML、表格和编号对象在导入前后比较。通过格式检查不代表译文已经人工审校。

当前仅在“更多 → 已有附件”中提供已有文件下载，没有新增导出系统。两篇受信示例原稿可下载；新上传 HTML 的原始文件仅管理员可下载，成员阅读清理后的内容。下载得到的文件不会自动与服务器同步。

## 安装、位置与维护

可运行源码在 `app/`，真实迁移在 `app/library/migrations/`，锁定依赖在 `requirements.lock`。本项目使用 Django 5.2.17、SQLite、Waitress、WhiteNoise；依赖安装在 `.venv`，不修改全局 Python。

目录布局（安装后）：

```text
app/              程序、可信样式脚本、迁移
.venv/            安装时创建的 Python 依赖环境（不提交）
var/              正式持久数据
  local.json      本机随机密钥与实例标识（保密）
  db.sqlite3      账户、元信息、分类、评分、评论
  papers/         原始 HTML、清理正文、图像和附件
  staging/        按账户隔离的临时上传
  logs/           预留本机运行日志位置
backups/          停机一致备份（含敏感账户资料）
evidence/         运行测试时生成的结果（不提交）
test-runs/        隔离测试与恢复演练数据，不是正式库
examples/         两篇示例论文、原文 PDF、段落映射
specs/            文章格式规范
templates/        标准双语文章骨架
tools/            测试与完整性校验工具
```

在另一台电脑或新的源码目录首次安装时，需要受支持的 Python，然后双击 **setup.cmd**。安装会联网下载锁定依赖，日常阅读无外网依赖。不要复制 `.venv` 到另一条路径；源码压缩包不包含它。可用环境变量 `PAPER_LIBRARY_PYTHON` 显式指定首次安装所用的 Python 可执行文件。

支持通过 `--data-dir "D:\论文库 数据"` 指定持久目录，或设置环境变量 `PAPER_LIBRARY_DATA`；setup、start、backup、账户管理必须始终指向同一目录。不要将 SQLite 放在网络共享盘、OneDrive 等同步目录。默认 `var` 位于当前本地项目目录，不应提交到 GitHub。

重复 setup 会先备份现有数据库与附件，保留服务器密钥和账户，只创建缺少的初始分类及参考论文。不会清分数、评论或恢复被隐藏的论文。需要维护前先停止应用。

## 备份与恢复

1. 停止网站，双击 **backup.cmd**。运行中的服务持有操作系统文件锁，备份会明确拒绝，不会只拷贝正在写入的数据库。
2. 备份完成后，窗口会显示 ZIP 路径。备份含数据库、全部论文文件、依赖版本与 SHA-256 清单，**含账户密码哈希，应按敏感资料保管**；不含服务器密钥、暂存、测试凭据。
3. 双击 **restore.cmd**，输入备份路径；默认恢复到新的 `restored/data-时间/`，不覆盖当前正式库。或运行：

```text
restore.cmd --archive "备份文件完整路径.zip" --target "D:\论文库恢复演练"
start.cmd --data-dir "D:\论文库恢复演练" --port 8001
```

恢复会检查路径安全、清单哈希、SQLite 完整性和附件引用；目标已经存在时拒绝覆盖。恢复后账户密码保留，服务器密钥重新生成，旧会话失效，需要重新登录。确认恢复目录正确后，可以以后都用明确的 `--data-dir` 入口启动它，保留原目录作为回退，不混用两个库。

备份 ZIP 应另存到外部设备。同盘副本无法应对整机或硬盘损坏。

## 验证与限制

本次公开包的验证结果见 [VERIFICATION.md](VERIFICATION.md)，复现方法见 [tools/TESTING.md](tools/TESTING.md)。测试使用隔离数据库和临时附件；`evidence/` 是执行时生成的本地结果，不随源码分发。新版页面的真实浏览器视觉检查和实际 Google 结果加载尚未执行。

本版适用于少量用户的低频写入场景。SQLite 的 15 秒忙等待和短事务不等于任意并发能力；50 人压力测试尚未执行。发生数据库忙或断网时界面提示未保存，可重试。

`check --deploy` 的 4 个 HTTPS 相关警告保留并记录：HSTS、强制 HTTPS、Secure session cookie、Secure CSRF cookie。它们是仅监听回环地址的本机 HTTP 例外；没有关闭 CSRF、鉴权或开启 DEBUG 来消除警告。
